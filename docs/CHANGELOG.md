# Changelog

## 2026-08-25 — Visual hierarchy polish

- 新增 `visual-polish.css` 最终视觉层，不改信息架构与业务行为，只统一视觉层级与表面关系。
- 主导航保留全部 6 个一级入口，但降低未选中按钮整块底色的饱和存在感，把模块辨识色集中到图标；当前页深色选中态保持不变。
- Header 的版本徽标与页面英文 Eyebrow 降低视觉权重，让中文标题、当前任务和状态成为第一视觉焦点。
- 每日、周计划、游戏、训练、资料库与时间页的分区背景整体减淡，减少多层浅色块叠加造成的“拼贴感”；白色任务卡成为更明确的内容主体。
- 被动状态标签统一为常规 6px 圆角和更轻边框，保留完成、逾期、运行、暂停等语义状态的原有颜色。
- 每日/周计划/游戏/训练/资料卡统一更安静的卡片边框和阴影；完成卡透明度从约 0.7 调整为 0.82，在保持弱化的同时提升可读性。
- Daily / Weekly / Game / Time 的指标小卡统一表面风格，折叠箭头去掉额外灰色小方块，降低界面中“小盒子套小盒子”的视觉碎片。
- 手机底部 6 项导航继续全部直显，仅强化为一个统一的浮动控制面；小屏分组背景进一步趋近白色，减少视觉疲劳。
- 增加 `prefers-contrast: more` 高对比度回退规则，视觉减法不会牺牲需要更强边界的用户。
- Service Worker 缓存升级为 `taskring-shell-20260825-3`，CI 增加 Visual 样式导入与离线缓存接线检查。

## 2026-08-25 — UX conservative polish

- 在桌面 Header 增加低对比度 `Alt 1–6 快速切换` 提示，仅在有鼠标/键盘且宽屏环境显示；六个一级导航按钮同时补充 `aria-keyshortcuts` 与完整快捷键 tooltip。
- 快捷键在总控或任意编辑/详情弹窗打开时停用，避免误切后台页面；任务卡“更多”菜单支持 `Esc` 快速关闭并恢复焦点。
- 收窄 `ux-efficiency.js` 的 MutationObserver 触发范围，只在任务卡、周分类、Orbit 或编辑器日志真正变化时重新增强，避免计时器等频繁 DOM 更新造成无意义全页扫描。
- 编辑器保留全部导入、导出、恢复等能力，不再继续藏入口；仅通过视觉层级突出“保存/新增”，降低同权重按钮造成的决策噪音。
- 编辑器处于“等待编辑”时不再常驻空黑色日志框；一旦出现真实保存、错误或状态输出即自动显示。
- Service Worker 缓存更新为 `taskring-shell-20260825-2`，并提升 UX JS/CSS revision，确保安装版接收本轮细化。

## 2026-08-25 — UX efficiency pass

- 总控从“第二套页面导航”收敛为编辑与维护中心：移除与底部/顶部主导航重复的“周计划池”“时间账本”入口，只保留任务、训练饮食、游戏和资料库四个配置编辑器。
- Header 隐藏重复的 GitHub 同步设置与快速锁定按钮；这两项仍保留在总控中，减少每日高频区视觉噪音。
- 每日模式切换改为更明确的“待执行 / 今日全部 / 本周矩阵”三段式；低频危险操作“重置本周”移动到总控的安全与维护区。
- 每日任务卡与周计划卡把补记、时间账本、目标编辑、任务编辑等低频动作收进“更多”，始终保留开始计时与外部链接等高频动作。
- 删除每日卡片第二行重复的日期/状态信息，缩短卡片高度并减少扫描负担。
- 周计划分类记住上次选择，刷新或重新进入时自动恢复，减少反复筛选。
- 今日 Orbit 概览在用户未主动设置过展开状态时默认收起，让页面更快进入实际任务列表；用户手动展开/收起后继续按原持久化逻辑记忆。
- 手机游戏作战区顶部控制由横向隐藏滚动改为直接网格展示，今日、进度、计时、补记、编辑不再需要左右寻找。
- 桌面端新增 `Alt+1`～`Alt+6` 主页面快捷切换，并为导航按钮补充快捷键提示。
- 新增 `ux-efficiency.js` 与 `ux-efficiency.css` 后置增强层；Service Worker 与仓库完整性检查同步覆盖这些资源。

## 2026-08-24 — Conflict-safe sync, data migration & CI

- 修复 Gist 自动读取可能把较新的本机配置静默替换为较旧云端配置的问题；配置同步改为基于共同指纹的三方判定。
- 本机和云端同时修改配置时不再自动选边覆盖：保留当前本机配置、记录云端冲突副本，并要求显式处理覆盖动作。
- 完成状态新增逐项 `value / updatedAt / deviceId` 元数据和删除 tombstone；取消完成与周期重置可以跨设备正确传播。
- 旧版仅保存 `"1"` 的完成状态首次升级时采用并集合并，避免迁移阶段因“缺少键”误删另一设备已有勾选。
- 修复公开 Demo 中 `time_category: "create"` 与 `time_category: "it"` 两个无效值，并兼容旧配置自动迁移到 `creator` / `it_ai`。
- `.gitignore` 新增 TaskRing 四类真实 JSON 导出文件规则，降低 `git add .` 误提交个人数据的风险。
- 新增 `integrity-core.js` 与 `data-integrity.js`，把纯数据合并逻辑和浏览器同步副作用分开。
- 新增 Node 内置测试与 GitHub Actions CI，覆盖同步冲突、状态 tombstone、分类迁移、运行资源/PWA 缓存一致性和 JavaScript 语法。
- Service Worker 缓存版本升级到 `taskring-shell-20260824-1`，并把新同步模块加入离线 APP_SHELL。
- 更新结构文档与同步相关 UI 文案，移除“从云端读取 = 覆盖本机状态”的旧描述。
