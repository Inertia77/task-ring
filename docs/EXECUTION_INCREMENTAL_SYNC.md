# Execution history and incremental sync

The existing workspace JSON is preserved as a compatibility snapshot for older deployed devices and full backups. An owner-scoped, indexed per-key table records the latest metadata and revision for every completion key. A transaction trigger keeps the index consistent with both old and new writes. The active/history views automatically classify known legacy date-cycle keys and gqv4 daily/weekly keys at 28 days (Asia/Tokyo); unknown key families, including durable one-time and learning states, stay active. No records are deleted, including tombstones.

The client bootstraps a complete state snapshot once per browser (or when the cursor is unavailable), retaining its local historical cache for historical views and task-code reuse protection. Subsequent reads request only records changed after the stored revision. The client merges by existing timestamp/sequence rules, then submits changed keys and changed time-log/deletion entries only. The server CAS guards the write and clients retry after a stale revision. The old full JSON is not included in ordinary workspace head reads or compact configuration save responses. Full backup export/import explicitly reads complete server history. Time logs are returned as a separate complete section only when that section changes; their historical records are retained.

The indexed views are a logical archive, not physical deletion or relocation from the compatibility snapshot. Local history stays available. After all clients adopt the new runtime, a further migration could retire the compatibility snapshot, but doing so is not required to eliminate repeated full-state network transfers.

Production checks: 4,531 indexed records, 3,913 historical and 618 active at initial verification; zero metadata mismatches. Empty delta 77 raw JSON bytes vs previous execution snapshot 973,265 bytes (configuration and game payloads separate). Rollback-only tests verified single-key write/uncheck, revision conflict, time log insert/delete, learning sequence, and RLS owner isolation.
