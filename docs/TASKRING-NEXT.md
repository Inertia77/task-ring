# TaskRing NEXT

任务总览按业务日期查询日常、周计划、游戏、生活改善和学习。定义使用来源和稳定 ID，执行实例另带日期、周一日期、序列序号或单次标识。原任务继续使用原完成键。周计划的「本周已执行」与计时目标并存，每周安排可选多日，指向同一个周实例。业务日期以日本时间 04:00 为界，限时活动沿用 JST 日历日期，已确认的精确时刻带时区。

学习语言和知识默认各有一条空队列。每轨每个序号有一条版本化状态，含学习项 ID、完成日与时间戳。完成当天显示原学习项，次日由历史重放决定下一项。末项可停止或循环。历史可撤销最后一项。已发生后续执行时，从最新一项往回处理。补记使用操作当天业务日期。编辑队列保留任务 ID。

T3 和原游戏选做进入「有余力」。游戏周常在周日进入执行视图，等待条件的周常留在专业面板。限时和周期任务通过原 Supabase 数据通道查询、完成和回读。当日完成可撤销，恢复原 UUID 和任务键。离线保留账号隔离缓存。

## 配置、备份与回滚

「任务管理 → 统一 JSON」提供一份配置导出和一份完整备份。导入检查版本、数据源、重复 ID 与状态编码，再预览差异。建立本机回滚点后应用。备份另含完成记录、撤销记录、时间账本和删除记录。恢复备份时按时间戳合并，保留较新的撤销。本机配置可从回滚点恢复。

- [统一配置格式](taskring-next-config.schema.json)
- [统一 JSON 示例](taskring-next-config.example.json)
- [兼容配置示例](taskring-config.example.json)

旧配置打开后按来源映射现有 ID 和完成状态，无批量数据重写。新功能第一次保存时增加版本标识和相关字段。Supabase 的表、历史与权限沿用已有部署。

刷新与重新打开会恢复本浏览器最近使用的工作台；首次打开默认进入任务总览。`?view=` 直达链接优先于本机记忆，打开链接后切换模块会同步更新该参数，避免刷新又跳回原来指定的页面。指定 `?date=` 的调试入口仍默认打开每日，后续手动切换也会保持当前模块。

## 代码入口

- assets/js/tasks/engine.js 处理日期、周期、排序和学习历史重放。
- assets/js/tasks/sources.js 连接各模块的读取、身份和写入。
- assets/js/tasks/config.js 验证配置、备份与导入差异。
- assets/js/tasks/command.js 提供总览、学习、任务管理和周计划共用控件。
- assets/css/command-center.css 提供新页面样式。手机底栏依次是「总览 → 生活改善 → 游戏 → 学习 → 更多」；「每日」「周计划」「时间账本」「资料库」和任务管理由「更多」进入。桌面保留全模块直接导航。

## 编辑配置工作台 v2（2026-11-18）

总控「编辑与维护」现在只有一个正式编辑入口。原四个编辑器按钮不再呈现为主导航卡片，旧编辑器本体仍保留供高级兼容用途，并通过工作台项目列表底部的折叠入口访问。

六个区域共用草稿与安全保存。支持分区数量、稳定分组过滤、启用状态筛选、分组搜索、上一项/下一项、撤销/重做（仅未保存草稿）、Ctrl/⌘+S 保存及 Ctrl/⌘+K 搜索；切换区域时保留选择与滚动位置。手机采用列表/详情两阶段全屏编辑。统一 JSON 管理通过全局工作台打开，无未保存草稿时可作为覆盖层使用，导入完成自动刷新工作台；Gist 同步、配置备份和 Supabase 权威数据源不变。旧编辑器仅作为特殊高级属性的兼容途径，避免功能丢失。
